Hexadecimal

Hexadecimal is base 16: 0–9 then A, B, C, D, E and F.

Two hex digits represent 00–FF.

Binary to hexadecimal

1010→A1111→F

Split an 8-bit binary number into two nibbles. 0011 1110 = 3E.

Binary shifts

A left shift moves bits left and usually multiplies by 2. A right shift moves bits right and divides by 2 using whole numbers.

Bits shifted out are lost; zeroes enter empty spaces.

Nibble: 4 bits = one hex digit.
Left: bits move left, zero enters on right.
Right: bits move right, zero enters on left.
Turn knowledge into marks

Question: Convert 10011100 into hexadecimal, then shift it right once. [5 marks]

Step 1 — split into nibbles

Write 1001 1100. Each group of four becomes one hexadecimal digit.

Step 2 — convert each nibble

1001 = 9 and 1100 = C, so the hexadecimal value is 9C.

Step 3 — shift right

Move every bit one place right: 01001110. The value changes from 156 to 78.

Convert 10011100 into hexadecimal, then shift it right once. [5 marks]

Hexadecimal: 9C.

Right shift: 10011100 → 01001110. The denary value is halved: 156 ÷ 2 = 78.

Hex and shift check

  1. Split binary into groups of 4.
  2. Convert each nibble.
  3. For a shift, move every bit.
  4. Add a zero in the empty place.
  5. Discard any bit that leaves 8 bits.
Improve the answer together

Question: Convert denary 175 to 2-digit hexadecimal. [4 marks]

Weak answer

“175 is 17 and 5, so it is 175 in hexadecimal.”

Improve it by dividing into groups of 16.

Possible improved answer

175 = 10 × 16 + 15. In hexadecimal, 10 is A and 15 is F.

The answer is AF.

Push it further

Why does right shifting an odd binary number sometimes lose part of the value?

Answer

The rightmost bit is discarded. With an odd number it represents 1, so the remaining whole-number result is rounded down.

Explain [5]

Explain how you convert a positive denary number to an 8-bit binary number.

Possible answer: Write the place values from 128 to 1. Start with the largest value. If it fits into the number, write 1 and subtract it; otherwise write 0. Continue through all eight places and read the result from left to right.
