Binary addition facts

0 + 0 = 0; 0 + 1 = 1; 1 + 1 = 10.

For 10, write 0 and carry 1 into the next column.

Add right to left

Line up the bits. Add the rightmost column first, then move left, carrying where needed.

1 + 1 + 1 = 11: write 1, carry 1.

Overflow

Eight bits can store 0–255. A result that needs a ninth bit is an overflow error.

The stored 8-bit result is not the true answer.

Start: at the right.
Carry: record it above the next column.
Check: is there a ninth bit?

Question: Add 01011011 + 00101101. State the 8-bit result and its denary value. [5 marks]

Step 1 — line up and start at the right

Write the two 8-bit values one above the other.

Step 2 — add and carry

Where a column totals two, write 0 and carry 1 to the left.

Step 3 — check the result

The result is 10001000. It has eight bits, so no overflow occurred.

Add 01011011 + 00101101. State the 8-bit result and its denary value. [5 marks]

01011011 + 00101101 ────────── 10001000

10001000 = 128 + 8 = 136. There is no ninth bit, so no overflow occurs.

Addition check

  1. Start at the right.
  2. Add the two bits and any carry.
  3. Write the answer bit.
  4. Carry where needed.
  5. Look for a ninth bit.

Question: Add 11100110 + 00110010 and explain the overflow error. [5 marks]

Weak answer

“It is too big, so the answer is wrong.”

Complete the addition and improve the explanation using 8 bits, 255 and overflow.

Possible improved answer

11100110 + 00110010 ────────── 1 00011000

230 + 50 = 280. Eight bits can store only 0–255, so the ninth carry bit cannot be stored. The stored result is 00011000. This is an overflow error.

Exam explanation [4]

Explain why an overflow result may cause a program to produce an incorrect answer.

Possible answer: The true result needs more bits than are available. The extra leftmost carry is lost, so the value stored is different from the true calculation.
